# 4. Finish setup and operate the server

## Configure HTTPS with Let's Encrypt

Before requesting a certificate:

- Point the domain's DNS A/AAAA record to the server's public IP address.
- Allow inbound TCP ports 80 and 443 through the cloud and host firewalls.
- Confirm that DNS resolves to the server.

Install Certbot and request a certificate:

```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d lms.example.com
sudo certbot renew --dry-run
```

Replace `lms.example.com` with your domain and select the HTTPS redirect option when prompted.

## Complete the Moodle installation

Open `https://lms.example.com` and follow the installation wizard:

| Setting | Value |
| --- | --- |
| Web address | `https://lms.example.com` |
| Moodle directory | `/var/www/moodle` |
| Data directory | `/var/www/moodledata` |
| Database type | PostgreSQL |
| Database host | `localhost` |
| Database name | `moodle` |
| Database user | `moodle` |
| Database password | The password created during database setup |

Because the code directory is intentionally not writable by the web-server account, the installer may display generated `config.php` content for you to save manually. Save it as `/var/www/moodle/config.php` and ensure it is readable by PHP but not writable by the web server. Follow the configuration directives generated by your installed Moodle release.

## Configure Moodle cron

Edit the `www-data` user's crontab:

```bash
sudo crontab -u www-data -e
```

Add this entry:

```cron
* * * * * /usr/bin/php /var/www/moodle/public/admin/cli/cron.php >/dev/null 2>&1
```

## Verify services

```bash
sudo systemctl status nginx
sudo systemctl status php8.3-fpm
sudo systemctl status postgresql
sudo nginx -t
php -m
```

## Production operations

| Area | Recommendation |
| --- | --- |
| Firewall | Enable UFW or the cloud firewall; expose only required ports. |
| Backups | Back up PostgreSQL, `moodledata`, and configuration; test restores. |
| Caching | Consider Redis for application and session caching after baseline testing. |
| PHP performance | Enable and tune OPcache; size PHP-FPM workers to available RAM. |
| Monitoring | Monitor CPU, memory, disk, PHP-FPM, Nginx, and database health. |
| Email | Configure a reliable SMTP relay and verify outbound mail. |
| Authentication | Consider Microsoft Entra ID SSO using a supported Moodle authentication integration. |
| Security | Keep Ubuntu, Moodle, PHP, and plugins patched; install plugins only from trusted sources. |

Take a full backup before every Moodle core or plugin upgrade.
